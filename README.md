## DKD NATION – E-commerce Website

An independent South African streetwear e-commerce website for DKD NATION (Dead King Demolition).

## About the Project

DKD NATION is a streetwear brand built around individuality, self-expression and the courage to stand apart.

This project involves developing an e-commerce website that reflects the brand's dark luxury, gothic-influenced and minimalist identity.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- SQLite (planned backend integration)
